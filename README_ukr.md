# Kefir 3

[English](README.md)

## Що таке Kefir

Це збірка, що складається з модифікованого Atmosphere, необхідних програм та скриптів, які все правильно встановлюють. Вона створена для полегшення встановлення та обслуговування програмного забезпечення на зламаній Nintendo Switch. Зміни, внесені в Atmosphere, спрямовані на покращення якості використання самої системи.

Головні відмінності від ванільного Atmosphere:
  * Версії Kefir поряд із версіями системи
  * Встановлення драйвера exFAT карти пам'яті за замовчуванням при оновленні системи
  * Видалення перевірки ACID підпису для використання homebrew без патчів
  * Видалення системного логування для запобігання засміченню карти пам'яті та надмірному використанню
  * Перенаправлення збережень з внутрішньої пам'яті на карту пам'яті при використанні emuNAND для зменшення ймовірності їх втрати у разі відмови emuNAND (опціонально)

**Kefir** — це **не прошивка**! Це збірка, що складається з прошивки Atmosphere та необхідного мінімуму рекомендованих програм, плагінів, модулів та іншого програмного забезпечення.

Остання підтримувана версія системи: **23.5.0**.

## Навіщо потрібен Kefir?

Перш за все, Kefir потрібен для спрощення життя користувача. Тобто, якщо у користувача є рекомендована версія системного програмного забезпечення та остання версія Kefir, то все повинно працювати для нього. Можна сказати, що користувач знаходиться в контрольованих умовах. Достатньо назвати версію системного програмного забезпечення та Kefir, і відразу стає зрозуміло, що приблизно встановлено в системі.

## Що нового в Kefir 3

У Kefir 3 є одна головна програма: **[Kefir Hub](https://github.com/rashevskyv/kefir-hub)** ([документація](https://hub.customfw.xyz)). Вона замінює кілька програм старої збірки:

| Раніше (Kefir 2) | Тепер (Kefir 3) |
|---|---|
| Sphaira, hbmenu | Kefir Hub (відкривається і як меню homebrew) |
| Kefir Updater | Kefir Hub → **Інструменти** → **Оновлювач** (оновлення Kefir) |
| Daybreak | Kefir Hub → **Інструменти** → **Оновлювач** (оновлення системи з ZIP або з теки) |
| Linkalho | Kefir Hub → **Інструменти** → **Інструменти** → **Користувачі** (прив'язка акаунта) |
| Меню Ultrahand: Settings, Software, Theme, Translate Interface | Kefir Hub → **Інструменти** → **Налаштування Кефіра**, **Додаткові програми** і **Теми** |

У Kefir Hub натисніть **R**, щоб відкрити **Інструменти**. Під час першого запуску короткі підказки покажуть, що де лежить.

## Склад Kefir

1. **[Kefirosphere](https://github.com/rashevskyv/Kefirosphere)**, форк [Atmosphere](https://github.com/Atmosphere-NX/Atmosphere)
2. **Патчі підписів**. Вони вбудовані в завантажувач Kefirosphere, також встановлено [sys-patch](https://github.com/impeeza/sys-patch). Завдяки їм, ви можете запускати непідписані (читай: *піратські*) програми та ігри на Atmosphere.
3. **Завантажувач [hekate](https://github.com/CTCaer/hekate)**: завдяки завантажувачу можна запускати прошивку та інші пейлоади через зручне меню, створювати та відновлювати бекапи NAND, створювати EmuNAND, дивитися стан системи, підключати карту пам'яті до ПК без виймання з консолі, перерозмічати карту для інших ОС і багато іншого
4. **Встановлені пейлоади**:
  * [Lockpick_RCM](https://github.com/impeeza/Lockpick_RCMDecScots) - програма для дампу ключів консолі
  * [TegraExplorer](https://github.com/rashevskyv/TegraExplorer/) - файловий менеджер для Switch у вигляді пейлоада. Аналог GodMode9 для 3DS. Kefir також встановлює через нього свої оновлення
5. **Встановлені Homebrew**
  * [Kefir Hub](https://github.com/rashevskyv/kefir-hub) - головна програма Kefir: меню homebrew, оновлення Kefir і системи, встановлення ігор (USB, MTP, мережа), збереження, прив'язка акаунта, теми, магазин homebrew, налаштування Kefir, системні інструменти
  * [DBI](https://github.com/rashevskyv/dbi) - програма для встановлення ігор через USB або з карти пам'яті. На ПК використовуйте з нею [DBI Backend Qt](https://github.com/rashevskyv/dbibackend-qt)
  * [NXThemes Installer](https://github.com/exelix11/SwitchThemeInjector) - менеджер користувацьких тем
  * [NX-Activity-Log](https://github.com/aoihera/NX-Activity-Log) - статистика ігрової активності Nintendo Switch
  * [pipensx](https://gitlab.com/pipensx-group/pipensx) - перегляд і завантаження з торрент-каталогу
  * [TorrentShopNX](https://github.com/Langegen/TorrentShopNX) - торрент-каталог для консолі
6. **Встановлені модулі**. Модулі — це додаткові компоненти, які працюють всередині Atmosphere і дозволяють робити різні круті речі, наприклад, використовувати Xbox-сумісні контролери, емуляцію amiibo, розгін тощо.
  * [sys-con](https://github.com/o0Zz/sys-con) - модуль для підключення майже будь-якого геймпада до консолі через USB
  * [Mission Control](https://github.com/ndeadly/MissionControl) - модуль для підключення майже будь-якого геймпада до консолі через bluetooth
  * [sys-patch](https://github.com/impeeza/sys-patch) - патчі підписів у пам'яті
  * [Ultrahand](https://github.com/ppkantorski/Ultrahand-Overlay) - оверлейне меню, відкривається комбінацією (L) + **хрестовина вниз** + (R3)
    - Пакети: **Semi-Stock** (завантаження в напівсток з меню), **Reboot** і **Shutdown**
    - Оверлеї:
      - [nx-ovlloader](https://github.com/WerWolv/nx-ovlloader) - завантажувач оверлеїв
      - [ovlEdiZon](https://github.com/proferabg/EdiZon-Overlay) - чити
      - [ovlSysmodules](https://github.com/ppkantorski/ovl-sysmodules) - вмикає і вимикає встановлені системні модулі
      - [sys-patch overlay](https://github.com/impeeza/sys-patch) - стан і налаштування sys-patch

## Інструкції з встановлення/оновлення kefir

### Перше встановлення або встановлення на чисту карту пам'яті

1. Скопіюйте **вміст** архіву `kefir.zip` з репозиторію в корінь карти пам'яті консолі
2. Вставте карту пам'яті в Switch
3. Запустіть консоль у прошивку відповідно до вашого типу злому. `payload.bin` - пейлоад, який треба інжектити при запуску консолі через Fusée Gelée, лежить в архіві зі збіркою

### Оновлення kefir або перехід з іншої збірки

#### Оновлення kefir безпосередньо на консолі (рекомендовано)

1. Відкрийте **Kefir Hub** (він запускається як меню homebrew)
2. Натисніть **R**, щоб відкрити **Інструменти**, і виберіть **Оновлювач** (потрібне підключення до Інтернету!)
3. Виберіть нову версію Kefir і встановіть її. Консоль перезавантажиться в TegraExplorer, який встановить Kefir
4. Після завершення встановлення консоль завантажиться в прошивку

> Цей самий **Оновлювач** встановлює оновлення системи. Daybreak у Kefir більше немає.

#### Інструкції з ручного встановлення (всі ОС)

##### Підключення карти пам'яті консолі до ПК

Якщо ви користувач MacOS, виконайте рекомендовані кроки, щоб уникнути проблем з картою пам'яті.

Якщо консоль вимкнена, вставте карту пам'яті в ПК. Якщо увімкнена:
1. Перезавантажте консоль через меню, яке викликається утриманням кнопки (POWER)
2. На заставці kefir натисніть кнопку зменшення гучності, щоб потрапити в hekate
3. Тепер можна вийняти карту пам'яті з консолі та вставити її в ПК.

> Якщо виймати карту пам'яті в hekate, не треба буде знову інжектити пейлоад для входу в прошивку. Просто вставте карту в консоль і запустіть прошивку через меню **Launch**

##### Встановлення kefir (всі ОС)

1. Скопіюйте **вміст** архіву `kefir.zip` з репозиторію в корінь карти пам'яті консолі
2. Вставте карту пам'яті назад у Switch
3. У **hekate** виберіть **More configs** -> **Update Kefir**
4. Після завершення встановлення консоль завантажиться в прошивку

> Також можна просто вимкнути консоль, вийняти з неї карту, скопіювати на неї kefir із заміною, вставити карту назад у Switch і увімкнути консоль. У цьому разі скрипт оновлення запуститься автоматично

> Оновлення видаляє програми, яких у Kefir 3 більше немає: Kefir Updater, Daybreak, Linkalho і старі меню Ultrahand.

#### Чисте встановлення kefir (рекомендується при виникненні помилок)

1. Видаліть з карти все, крім тек `Nintendo` та `emummc`, якщо вони є
2. Встановіть kefir зручним способом, описаним вище

#### Налагодження встановлення kefir (рекомендується, якщо чисте встановлення не допомогло)

1. Скопіюйте теки `Nintendo` та `emummc`, якщо вони є, на ПК
2. Відформатуйте карту пам'яті в FAT32 і поверніть теки назад
3. Встановіть kefir зручним способом

### Усунення несправностей

Якщо виникає помилка [NOFAT] або будь-яка інша проблема з оновленням через скрипт оновлення, встановіть kefir через `install.bat`:

1. Розпакуйте `kefir.zip` у будь-яке зручне місце **на ПК**, *крім карти пам'яті консолі*
2. **Вставте в ПК** карту пам'яті консолі
3. Запустіть `install.bat` з теки, куди розпакували `kefir.zip`, і вкажіть літеру вашої карти пам'яті
4. Дочекайтеся завершення копіювання
5. Вставте карту в консоль і запустіть прошивку

> Якщо з'являється помилка "**Is BEK missing**", вимкніть консоль і увімкніть її знову.

## Запуск Atmosphere

Якщо після входу в прошивку консоль не бачить карту і для роботи з нею вимагає оновити прошивку, або просто зависає на чорному екрані після логотипу Nintendo, то на вашій консолі не встановлені драйвери exFAT! Відформатуйте карту пам'яті в FAT32.

У hekate за замовчуванням увімкнено автозапуск. Тобто під час старту консолі меню hekate не показується, а одразу запускається прошивка. Щоб потрапити в меню hekate, утримуйте (VOL-) під час появи заставки.

### **Важлива інформація!**

  * Перезавантаження в hekate відбувається прямо з прошивки, через звичайне меню перезавантаження. Просто утримуйте (VOL-) під час заставки kefir
  * Доступ до карти пам'яті без виймання з консолі — через MTP у **Kefir Hub** або **DBI** (**Run MTP Responder**), або через hekate (не у всіх працює коректно, **оновлювати kefir через MTP не можна**)
  * Встановлення та оновлення kefir виконуються однаково!
  * Якщо виникає помилка "**Is BEK missing**", вимкніть консоль і увімкніть її знову.

## Додаткова інформація
* Налаштування Kefir — у **Kefir Hub** → **Інструменти** → **Налаштування Кефіра**: розгін, пам'ять аплетів 40 МБ, USB 3.0, збереження emuMMC на карті пам'яті, режим 8 ГБ пам'яті, Nextendo, переклад інтерфейсу
* Оновлення DBI і магазин homebrew (App Store) — у **Kefir Hub** → **Інструменти** → **Додаткові програми**
* Щоб перейти в напівсток
  * **З самої прошивки**: відкрийте Ultrahand ((L) + **хрестовина вниз** + (R3)) > `Kefir Menu` > `Semi-Stock Status`
  * **Під час запуску консолі**: перейдіть у hekate і виберіть `More-configs` > `Semi-stock (Legacy)`
  * Зверніть увагу: під час запуску з прошивки встановлена тема вимикається. Це допомагає уникнути помилок, якщо версії системи в sysNAND і emuNAND різні
* Оновити kefir і версію системи можна в **Kefir Hub** → **Інструменти** → **Оновлювач**

### Розгін
* Щоб увімкнути або вимкнути розгін, відкрийте **Kefir Hub** → **Інструменти** → **Налаштування Кефіра** → `Статус розгону`

### Режим підтримки 8ГБ пам'яті
* **Лише для консолей з фізично перепаяними 8 ГБ оперативної пам'яті.** Інші консолі не завантажаться коректно
* **Увімкнення**: **Kefir Hub** → **Інструменти** → **Налаштування Кефіра** → `Статус 8 ГБ оперативної пам'яті`
* **Вимкнення**, якщо консоль не завантажується: hekate > `Payloads` > `TegraExplorer` > `Remove_8GB-RAM_config.te`, або перевстановіть kefir
